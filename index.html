Попробуйте приложение прямо здесь.

Те же экраны React Native, которые используются на телефоне. Установка и Expo Go для этого просмотра не нужны.

  1. Найдите блюдо и добавьте в корзину.
  2. Нажмите «Тестовая покупка» и получите код.
  3. Для проверки выдачи переключитесь в «Заведение».
Полный сценарий
